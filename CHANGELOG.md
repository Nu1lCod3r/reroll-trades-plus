# Changelog

Все заметные изменения мода документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [2.0.1-beta] — 2026-11-12

### Added

- Сборка для **NeoForge 26.3** (NeoForge 26.3.0.102+): тот же функционал, те же цены и механики; Fabric API не требуется. Исходники лежат в папке `neoforge/` того же репозитория, jar — `reroll-plus-plus-neoforge-2.0.1-beta.jar`.

### Fixed

- **Реролл больше не ресточит торги.** Раньше реролл обнулял счётчики использования всех предложений — проданный (залоченный) торг разблокировался, и реролл работал как бесплатный ресток в обход дневных лимитов и роста цен от спроса. Теперь состояние (`uses` и спрос) переносится с прежних предложений на совпадающие новые: реролл меняет **набор** сделок, но не их состояние; залоченные торги остаются залоченными до обычного ванильного рестока. Торги, которых не было в прежнем наборе, свежие как и раньше.
- Добавлена проверка `isAlive()` торговца перед рероллом — нельзя «продать» реролл умирающему торговцу и потерять изумруды.
- Серверный кулдаун 0.5 с на запросы реролла: удержание клавиши/макросы больше не спамят пакетами, звуками и частицами, видимыми всем игрокам рядом.

## [2.0-beta] — 2026-11-11

Первый публичный бета-релиз.

### Added

- **Реролл сделок жителей**: кнопка ↻ рядом с экраном торговли — житель получает свежий полный набор сделок своего уровня (генерация через ванильные `TradeSet` по всем уровням 1..N).
- **Реролл зачарований в столе зачарований**: обновляет три предложения за 1 лазурит из слота стола; реализован через ванильный механизм кнопок меню (id 3), полностью серверный.
- **Механика отказа**: торговец может отказаться от реролла — шанс растёт с уровнем (Обычный 0% → Мастер 20%, странствующий торговец 10%). При отказе изумруды не списываются, звучит `villager.no` и появляются злые частицы.
- **Поддержка странствующих торговцев** (реролл за 1 изумруд).
- **Горячая клавиша R** (переназначается в управлении) — реролл прямо из открытого экрана торговли.
- Цена реролла отображается на кнопке в стиле счётчика предметов; при нехватке изумрудов кнопка неактивна.
- Звук и частицы при успешном реролле (`villager.yes` + счастливые частицы) и при отказе.
- Кнопки — боковые вкладки 20×20 с ванильным фоном кнопки, снаружи слева от панелей (экран торговли и стол зачарований).
- Кнопки и весь серверный функционал активны только когда мод стоит на обеих сторонах; на ванильном сервере интерфейс не меняется.
- Иконка мода и текстура кнопки, локализация: английская и русская.

### Changed

- Переименование мода: id `reroll_trades_plus` → `reroll_plus_plus`, пакет `com.nullcoder.rerolltradesplus` → `com.nullcoder.rerollplusplus`, имя **Reroll Plus Plus**, автор NullCod3r.
- Версия 1.0-beta → 2.0-beta.

### Fixed

- Краш при открытии экрана торговли на клиенте: mixin больше не использует `@Shadow` унаследованных полей (в 26.3 у Minecraft нет обфускации и mixin refmap) — доступ через accessor-миксины на класс-объявитель.

### Технические детали

- Minecraft 26.3, Fabric Loader ≥ 0.20.1, Fabric API 0.165.2+26.3, Java 25, Mojang-маппинги (Loom 1.19).
- Кастомный C2S-payload `reroll_plus_plus:reroll_trades` для сделок; реролл зачарований — штатный `ServerboundContainerButtonClickPacket` (id 3).
- Вся валидация (открытое меню, дистанция `stillValid`, спекратор, наличие изумрудов/лазурита) выполняется на сервере.

## [1.0-beta] — 2026-11-07

Внутренняя сборка: кнопка реролла сделок с ценой в изумрудах, без странствующего торговца, хоткея и механики отказа.
